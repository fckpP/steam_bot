# Seam-аналитик бот:

Телеграм-бот для поиска информации об играх Steam.

## Что умеет бот:
- Искать игру по ID (например, `/game 730`).
- Искать игру по названию (например, `/game portal 2`).
- Присылать обложку игры и краткое описание.

## Технологии:
- Python 3
- python-telegram-bot
- Steam API (requests)

## Как запустить бота:
1. Установите зависимости: `pip install requests python-telegram-bot`
2. Вставьте свой токен в переменную `TOKEN` в файле `main.py`.
3. Запустите: `python main.py`
